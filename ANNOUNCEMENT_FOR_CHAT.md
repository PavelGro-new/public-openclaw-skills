Коллеги, привет!

Запаковал несколько reusable skills из своего агента Громика для OpenClaw. Можно посмотреть, забрать и адаптировать под своих агентов.

Внутри есть README и инструкции по установке:

- `aviasales-price-watch` — самый стабильный skill: мониторинг цен авиабилетов через Aviasales / Travelpayouts API.
- `voice-transcription` — beta: локальная транскрибация голосовых через ffmpeg + transcribe.cpp + локальную модель.
- `tour-price-watch` — beta: мониторинг пакетных туров через providers.

Важные оговорки:

- Для Aviasales нужен свой Travelpayouts token.
- Для Travelata API доступ нужно отдельно запрашивать через Travelpayouts/Travelata support или партнёрский канал; просто так в кабинете он может не лежать.
- TEZ provider проще, но доступность всё равно может зависеть от сети, IP и изменений API.
- Транскрибация длинных голосовых зависит от железа и модели. 2 часа аудио не обещаю; лучше тестировать постепенно: 5 минут, 15 минут, 30 минут.
- Не коммитьте свои `.env`, токены, chat_id, state, logs и реальные watches.
- Перед запуском внимательно прочитайте README.
