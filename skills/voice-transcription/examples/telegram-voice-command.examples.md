# Telegram Voice Command Examples

Examples of user-facing requests:

- "Transcribe this voice message."
- "Summarize this voice note into bullet points."
- "Turn this voice message into tasks."
- "Use this voice note as a prompt for Codex."
- "This is part 1 of an interview. Transcribe it, do not summarize."

Recommended testing path:

1. 10-30 second voice note.
2. 2-5 minute audio.
3. 15 minute audio.
4. 30 minute audio.

Do not start with multi-hour recordings.
